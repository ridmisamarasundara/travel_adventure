# 🌍 Travel Adventure Website

A collaborative **Travel Adventure Website** developed as a team project to learn and practice the **GitHub collaboration workflow**. This project focuses on understanding how multiple developers can work together using GitHub features such as repositories, branches, pull requests, code reviews, and issue tracking.

---

## 📖 Project Overview

The Travel Adventure Website allows users to explore travel destinations and adventure activities through a modern web interface.

The primary objective of this project was **not only to build a website**, but also to gain hands-on experience with collaborative software development using GitHub.

## 👥 Team Collaboration Workflow

Our team followed the GitHub collaboration process below:

1. One member created the GitHub repository.
2. Team members were added as collaborators.
3. Each member cloned the repository.
4. Individual feature branches were created.
5. Members committed their changes locally.
6. Changes were pushed to GitHub.
7. Pull Requests were created.
8. Team members reviewed the code.
9. Pull Requests were merged into the main branch.
10. Everyone pulled the latest updates.

This workflow helped us understand professional software development practices.
